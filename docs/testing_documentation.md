# Документация по тестированию

## Обзор

Этот документ описывает стратегию тестирования для проекта автоматизации откликов на hh.ru. Проект следует методологии TDD (Test-Driven Development), где тесты пишутся до реализации функциональности.

## Структура тестов

Тесты разделены на два основных типа:

1. **Юнит-тесты** - расположены в директории `tests/unit/`
2. **Интеграционные тесты** - расположены в директории `tests/integration/`

### Юнит-тесты

Юнит-тесты проверяют отдельные модули приложения изолированно. Каждый модуль имеет соответствующий файл тестов:

- `tests/unit/test_config.py` - тесты для модуля конфигурации
- `tests/unit/test_browser_config.py` - тесты для модуля настройки браузера
- `tests/unit/test_auth.py` - тесты для модуля авторизации
- `tests/unit/test_navigation.py` - тесты для модуля навигации
- `tests/unit/test_vacancy_processor.py` - тесты для модуля обработки вакансий
- `tests/unit/test_application_sender.py` - тесты для модуля отправки откликов
- `tests/unit/test_error_handler.py` - тесты для модуля обработки ошибок
- `tests/unit/test_logger.py` - тесты для модуля логирования

### Интеграционные тесты

Интеграционные тесты проверяют взаимодействие между модулями:

- `tests/integration/test_module_integration.py` - тесты взаимодействия между модулями
- `tests/integration/test_full_scenario.py` - тесты полного сценария работы скрипта

## Используемые инструменты

- `pytest` - фреймворк для написания и запуска тестов
- `pytest-mock` - плагин для создания моков
- `pytest-asyncio` - плагин для тестирования асинхронного кода
- `unittest.mock` - встроенный модуль для создания моков

## Стратегия тестирования

### Моки

Все тесты используют моки вместо реальных подключений к hh.ru. Это позволяет:

- Ускорить выполнение тестов
- Избежать зависимости от внешних факторов
- Проверить различные сценарии без необходимости в реальном аккаунте

### Покрытие

Тесты покрывают:

- Все основные функции и методы каждого модуля
- Граничные условия и ошибочные ситуации
- Взаимодействие между модулями
- Обработку ошибок

## Запуск тестов

Для запуска всех тестов используйте команду:

```bash
uv run python -m pytest
```

Для запуска только юнит-тестов:

```bash
uv run python -m pytest tests/unit/
```

Для запуска только интеграционных тестов:

```bash
uv run python -m pytest tests/integration/
```

Для получения детального вывода:

```bash
uv run python -m pytest -v
```
