## Новая переменная конфигурации

В проект добавлена новая переменная конфигурации `FAKE`:

- `FAKE=False` (по умолчанию) - скрипт работает как обычно, отправляя реальные отклики
- `FAKE=True` - скрипт имитирует выполнение всех действий, но не нажимает кнопки отправки откликов, что позволяет тестировать логику без отправки реальных откликов

Эта переменная может быть установлена через переменную окружения `FAKE` или в файле `.env`.
