# Отчет о добавлении переменной FAKE в проект hh_auto_responder

## Цель

Добавить переменную конфигурации `FAKE`, которая при значении `True` позволяет запускать скрипт в режиме, когда реальные отклики не отправляются (кнопка "Откликнуться" не нажимается).

## Выполненная работа

### 1. Добавление переменной FAKE в конфигурацию

- В `src/config.py` добавлено поле `FAKE: bool = False` в класс `Config`
- В функцию `get_config_from_env()` добавлена логика для чтения переменной окружения `FAKE`
- Реализована конвертация строковых значений в булево (true/True/1/yes/on -> True, false/False/0/no/off/"" -> False)

### 2. Обновление бизнес-логики

- В `src/business_logic/application_handler.py` добавлена проверка `if self.config.FAKE:` перед выполнением реальных действий
- Если `FAKE=True`, то реальные клики по кнопкам не производятся, и возвращается результат "Успешно (FAKE)"
- В лог добавлено сообщение о том, что режим FAKE включен

### 3. Обновление устаревшего модуля

- В `src/application_sender.py` также добавлена проверка переменной `FAKE` в методе `apply_to_vacancy`
- При включенном режиме FAKE не происходит реальных кликов и возвращается результат "Успешно (FAKE)"

### 4. Обновление документации

- В `README.md` добавлена информация о новой переменной окружения `FAKE`
- В документацию добавлено описание режима работы скрипта с этой переменной

### 5. Обновление тестов

- Созданы новые тесты для проверки работы переменной `FAKE`
- Обновлены существующие тесты, чтобы они корректно работали с новой функциональностью
- Добавлены тесты, проверяющие, что в режиме `FAKE=True` не происходит реальных кликов по кнопкам

## Результаты

Теперь проект поддерживает режим работы с переменной `FAKE`:

- При `FAKE=False` (по умолчанию) - скрипт работает как обычно, отправляя реальные отклики
- При `FAKE=True` - скрипт имитирует выполнение всех действий, но не нажимает кнопки отправки откликов, что позволяет тестировать логику без отправки реальных откликов

## Использование

Для запуска в режиме без реальных откликов установите переменную окружения:

```bash
export FAKE=true
```

Или добавьте в файл `.env`:

```
HH_LOGIN=ваш_email
HH_PASSWORD=ваш_пароль
FAKE=true
```
