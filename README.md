# hh_playwright

Автоматизация откликов на hh.ru с использованием Playwright

## Установка

1. Убедитесь, что у вас установлена Python версия 3.13 или выше
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

Или используйте uv (рекомендуется):

```bash
uv pip install -r requirements.txt
```

3. Установите браузеры для Playwright:

```bash
playwright install
```

## Запуск авторизации

Для запуска процесса авторизации выполните:

```bash
python main.py
```

Во время выполнения вам будет предложено ввести SMS-код, который придет на указанный номер телефона.

## Структура проекта

- `main.py` - точка входа в приложение
- `src/` - основной код приложения
  - `config.py` - конфигурационные параметры
  - `hh_session.py` - класс для управления сессией браузера
  - `step.py` - базовый класс для шагов
  - `hh_bot.py` - основной класс бота
  - `steps/` - шаги автоматизации
    - `hh_auth.py` - класс шага авторизации с интерактивным вводом SMS-кода
- `tools/` - служебные модули (logger, decorators, telegram integration)
- `docs/` - документация
